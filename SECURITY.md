# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in ALF, please **do not** open a public
GitHub issue. Instead, report it privately by emailing
[oss@instadeep.com](mailto:oss@instadeep.com) with:

- A description of the vulnerability and its potential impact
- Steps to reproduce or a proof-of-concept
- Any suggested mitigation, if known

We will acknowledge your report within 5 business days and aim to provide a
resolution or status update within 30 days. We will credit reporters in the
release notes unless anonymity is requested.
