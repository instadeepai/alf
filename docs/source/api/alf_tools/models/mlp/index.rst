MLP Model
=========

A Multi-Layer Perceptron (MLP) model implementation for sequence prediction tasks. This module
provides the core :class:`~alf_tools.models.mlp.MLP` network, the :class:`~alf_tools.models.mlp.MLPModel` wrapper that integrates it with the ALF
framework, and the :class:`~alf_tools.models.mlp.MLPModelConfig` and :class:`~alf_tools.models.mlp.MLPTrainConfig` dataclasses for configuration.
