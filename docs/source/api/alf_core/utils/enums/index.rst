Enums
=====

The :mod:`alf_core.utils.enums` module defines enumeration types used across the ALF framework.
:class:`~alf_core.utils.enums.ProblemType` specifies whether a task is regression or classification, and
drives metric selection, model output dimensionality, and data splitting behaviour.
